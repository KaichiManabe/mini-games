ふたりの神経衰弱の遊び方

「ふたりの神経衰弱」は、裏返したカードを2枚ずつめくって同じ絵柄のペアを集める、2人対戦の神経衰弱（メモリーゲーム）です。トランプがなくても、スマホ1台を交代で使ってすぐに遊べます。

ルール

  1. カードの枚数を16枚・20枚・30枚から選びます（最初は20枚）。果物や食べ物、動物の絵柄が2枚ずつ入っています。
  2. 先手はランダムに決まります。点数の枠が光っているほうの番です。
  3. 自分の番にカードを2枚めくります。同じ絵柄ならペアを獲得して、もう一度めくれます。
  4. 違う絵柄なら、約1秒後に裏に戻り、相手の番になります。
  5. すべてのペアがそろったら終了。ペアが多いほうの勝ち、同じ数なら引き分けです。

取ったペアは、取った人の色の枠で表向きのまま残ります。「もう一回」で並べ直して最初から遊べます。

勝つためのコツ

  • 相手がめくったカードも覚える。自分の番以外も、めくられた絵柄と場所はすべてヒントです。
  • 1枚目は、まだ見ていないカードをめくる。出た絵柄が前に見たものなら、2枚目でそのカードをめくって確実にペアにできます。
  • 当てがないときは、2枚目に見たことのあるカードをめくる。新しいカードを2枚めくると、相手に場所を教えるだけになりがちです。
  • 場所に名前をつけて覚える。「左上の角」「右から2列目」のように言葉にすると、位置を忘れにくくなります。

よくある質問

1人でも遊べますか？
2人対戦用のゲームですが、1人で両方の番を担当すれば、記憶力の練習として遊べます。
1回の番で何枚めくれますか？
2枚です。ペアがそろえば続けて2枚めくれるので、覚えていれば連続で取り続けることもできます。
引き分けになることはありますか？
16枚（8ペア）と20枚（10ペア）では、取ったペアの数が同じになって引き分けることがあります。30枚（15ペア）は必ず決着がつきます。
